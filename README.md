# geometric-figure-viewer（図形エディター）

球・三角柱・四角柱・平面などの単純な図形を組み合わせて、人型の全身3Dモデルを作るブラウザ用エディターです。ビルド不要で、`index.html` を開くだけで動きます（Three.js r180 を使用）。

## 主な機能

- **図形の追加と編集**: 立体（球・三角柱・四角柱・断面）、平面（円・三角・四角）を追加し、移動・回転・拡縮ギズモや「寸法」パネル（cm・度）で編集。モーフ（角の丸み・球への変形・先細り）、傾き、細かさ、盛り上がり
- **左右対称編集**: 対称オンで左右1組のパーツを置き、片側の編集を反対側に反映
- **マスク（切り抜き）**: 図形と重なる範囲を非表示にする。フォルダやリンクパーツ単位でもまとめて切り抜き可能
- **パス（ベジエ曲線・ループ）**: パーツやリンクをパスに沿わせて曲げる・等間隔に並べる。クリックで点を打って描くことも可能
- **結合・ラスタライズ**: 複数パーツを1つのメッシュに結合（manifold-3d を使用）、変形を焼き込み
- **アウトライナー**: フォルダ分け、並べ替え、表示/非表示、ロック、色設定
- **リンクモデル**: パーツやフォルダを別モデル化して別タブで編集し、変更を元のモデルに自動反映
- **柔らかさ**: 胸・髪・しっぽ等の垂れ・揺れ表現と、その確認用編集モード
- **ボーンとモーション**: 自動配置されるボーンにパーツを割り当て、MMD（.vmd）や .bvh モーションを再生
- **法線編集・画像の投影・顔/手/足の部品生成・下書きレイヤー**
- **Undo/Redo、コピー＆ペースト、JSON の保存・読み込み・インポート**

## 起動方法

### npm を使う場合

```bash
npm start   # http://localhost:8765/ で配信
```

ブラウザで http://localhost:8765/ を開きます。`#loading` の表示が消えれば準備完了です。

### npm install なし／静的ホスティング（GitHub Pages など）

Three.js（0.180.0）と manifold-3d（3.5.4）は `index.html` の importmap で CDN（jsDelivr）から読み込むため、`npm install` は不要です。リポジトリをそのまま任意の静的サーバー（`python3 -m http.server` など）や GitHub Pages で配信すれば動きます。

- ES Modules を使うため、`file://` で直接開くのではなく HTTP で配信してください。
- 初回起動時にインターネット接続（CDN へのアクセス）が必要です。
- `package.json` の依存関係はバージョン管理と、オフラインで使いたい場合のためのものです。オフラインで使う場合は `npm install` したうえで、importmap の URL を `./node_modules/three/build/three.module.js` などに書き換えてください。

## 操作方法

詳しい説明はアプリの「ヘルプ」（操作ガイド）にあります。主な操作は次のとおりです。

### マウス

| 操作 | 内容 |
|---|---|
| クリック | パーツを選択 |
| Shift+クリック | 選択に追加 |
| ドラッグ（パーツ以外） | 視点の回転・平行移動 |
| ホイール | 拡大・縮小 |
| 右クリック（パーツ・フォルダ） | コンテキストメニュー（マスク編集・名前変更・ロック・削除・色設定・別モデル化など） |
| Shift+ギズモのドラッグ | 移動: つかんだ軸以外の方向へ ／ 回転: 45度刻み ／ 拡縮: 反対の面を固定 |
| 左のスケール（ルーラー）のドラッグ | 上下スケールの起点を移動（ダブルクリックで戻す） |

画面右下のアイコンでワイヤーフレーム・自動回転・パース（平行投影）を切り替えられます。

### キーボード

| キー | 内容 |
|---|---|
| Ctrl+S | 保存 |
| Ctrl+N | 新規作成 |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直し |
| Ctrl+A | すべて選択 |
| Ctrl+C / Ctrl+V | コピー / 少しずらして貼り付け |
| Delete / Backspace | 選択中のものを削除 |
| L | ロックの切り替え |
| F2 | 名前の変更 |
| Space | モーションの再生／一時停止（ボーンとモーション編集中） |
| Enter / Esc | パス描画の確定、各編集モードの終了、寸法入力の確定 / 取り消し |

（macOS では Ctrl の代わりに ⌘ も使えます）

## 保存について

- 保存は明示的に行います（Ctrl+S または「ファイル」メニュー）。保存すると次の2つが行われます。
  1. ブラウザの **localStorage** に保存（次回起動時に自動で開かれます）
  2. **`figure.json`** をダウンロード
- localStorage はブラウザ・オリジン（URL）ごとに別で、容量にも上限があります。大きなモデルは localStorage に入りきらないことがあるため、ダウンロードした JSON ファイルを保管し、「ファイル」→「読み込み」から開けるようにしておいてください。
- localStorage のキー: 本体 `geometric-figure-viewer`、リンクモデル `geometric-figure-viewer:model:<id>`、クリップボード `geometric-figure-viewer:clipboard`、レイアウト `geometric-figure-viewer:layout`

## JSON 形式（概要）

```jsonc
{
  "version": 1,             // 必須。現在は 1
  "name": "…",              // モデル名（リンクモデルで使用）
  "symmetric": true,        // 左右対称編集のオン/オフ
  "torso": [x, y, z],
  "guide": { "position": [...], "scale": [...] },
  "records": [              // 必須。パーツの一覧
    { "kind": "box", "solo": false,
      "mesh":   { "id": "shape-1", "kind": "box", "label": "…", "parent": "edits",
                  "folderId": "folder-1", "position": [...], "quaternion": [...], "scale": [...], … },
      "mirror": { … }       // 左右対称の反対側（ある場合）
    }
  ],
  "folders": [ … ],         // アウトライナーのフォルダ
  "curves": [ … ],          // パス（カーブ・ループ）
  "sketches": [ … ],        // 下書きレイヤー
  "rig": { … },             // ボーンの配置と割り当て
  "links": [ … ],           // リンクパーツ（リンク先モデルの id・位置・向き・拡縮など）
  "models": { "<id>": { … } } // 保存ファイルに同梱されるリンク先モデル
}
```

読み込み時には `version` と `records` を含む内容の検証が行われ、不正なデータは読み込まれません。`samples/` にサンプルのモデルファイルがあります。

## リンクモデルの仕組み

- パーツやフォルダを右クリックして「別モデル化して別タブで編集」を選ぶと、その中身が別のモデルとして localStorage（`geometric-figure-viewer:model:<id>`）に保存され、`?model=<id>` 付きの URL で別タブが開きます。
- 元のモデルでは、それが1つの「リンクパーツ」として表示され、まとめて移動・回転・拡縮・マスク・左右対称配置ができます（中身はリンク先のタブで編集）。
- リンク先タブでの変更は自動で localStorage に書き込まれ、`storage` イベントで元のタブに即座に反映されます。
- ファイル保存時は、リンク先モデルが `models` に同梱されます。別のブラウザで読み込んだ場合も、同梱分が localStorage に復元されます。リンク先が見つからない場合は、右クリックの「リンクをつけなおす…」から保存済みファイルを選んで復旧できます。

## ディレクトリ構成

- `index.html` … アプリ本体（HTML・CSS・JavaScript をすべて含む）
- `samples/` … サンプルのモデルファイル（.json）
- `references/` … 参考画像
- `motions/` … サンプルのモーション（.bvh）と生成スクリプト
